# React SPA – Early Childhood Learning App

## Overview
This project is a **single‑page application (SPA)** built with the latest **React** framework. Its purpose is to support early speech development for very young children (around 2 years old) who are beginning to learn letters, numbers, and basic vocabulary.

The application provides an interactive, child‑friendly learning experience by reacting instantly to keyboard input.

---

## Features

### 🔤 Character Display
- Pressing any **letter** or **number** on the keyboard displays the corresponding character on the screen.

### 🖼️ Visual Learning
- For letters, the app shows:
    - An illustrative **graphic** representing a word starting with the selected letter.
    - A **colorful, simple UI** designed specifically for toddlers.

### 🔊 Audio Feedback
- Audio playback of:
    - The **letter pronunciation**.
    - An **example word** beginning with that letter.

---

## Technical Architecture

- Built as a **React-based SPA** for smooth, instant interaction without page reloads.
- Designed as a **serverless application**, minimizing backend complexity and enabling scalable, cost‑efficient deployment.
- Media assets (images, audio files) are loaded dynamically for optimal performance.
- The UI is optimized for **large buttons, high contrast, and minimal distractions**, making it suitable for very young children.

---

## Target Audience
Children around **2 years old** who are beginning to learn:
- Letters
- Numbers
- Basic vocabulary
- Sound–image associations

---

## Purpose
The application aims to create a fun, intuitive, and educational environment that encourages toddlers to explore language through visual and auditory cues.
